## 山姆代购管理工具 - 品牌词 UI 可编辑改造 (v4)

### 问题
品牌词硬编码在3处（BRAND_WORDS/EN_BRANDS/MULTI_WORD_BRANDS），每次新品牌出现需改代码，不可持续。

### 改造方案
1. **品牌词统一为一份列表** `DEFAULT_BRAND_WORDS`，存储在 localStorage（key: `sam_brand_words`）
2. **EN_BRANDS / MULTI_WORD_BRANDS 自动推导**：英文开头→英文品牌，含空格→多词品牌
3. **导入页底部添加可折叠品牌词管理面板**：添加/删除/恢复默认
4. **品牌词分三类标签显示**：🔵蓝色=英文品牌 🟡黄色=多词品牌 ⬜灰色=中文关键词
5. `BRAND_WORDS` 改为函数调用 `BRAND_WORDS()`，确保 UI 修改后解析立即生效

### 关键代码变更
- `DEFAULT_BRAND_WORDS` 替代原硬编码 `BRAND_WORDS` 数组
- `loadBrandWords()` / `saveBrandWords()` 读写 localStorage
- `getEnBrands()` / `getMultiWordBrands()` 自动推导
- `splitGoodsSmart` 和 `extractNameAndGoodsV2` 改用动态推导
- 新增 UI: 品牌词管理面板（可折叠）、添加输入框、标签列表、恢复默认按钮
