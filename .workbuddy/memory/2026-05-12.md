## 山姆代购管理工具 - 规格×数量语义修复 (v6, BUG-15/16)

### 问题
v5 修 #4 时引入过度纠正：`parseQty` 的 `isSpecMultiplier` 只要 × 前以规格单位结尾，
就无条件把 ×N 当装箱规格（`return {name: t, qty: 1}`），导致
`Member's Mark 酸奶 1.8kgX2` → name 含 "1.8kg×2" 且 qty=1（件数丢失）。

### 修复
1. 新增常量 `PACK_SPEC_MIN = 10`（index.html 顶部，QTY_UNITS 下方）
2. `parseQty` 的 isSpecMultiplier 分支按阈值分流：
   - `qty >= PACK_SPEC_MIN` → 装箱规格，整体保留 name，qty=1（300毫升×48）
   - `qty <  PACK_SPEC_MIN` → 件数，剥离数字，name 只到规格（1.8kg×2 → qty=2）
3. 修复副作用：`splitGoodsSmart` Step1.5 的保护占位符 `⨯` 不能被"数量×"规则匹配，
   否则 `MM300毫升×48矿泉水` 会被拆成 `MM300毫升`+`矿泉水`
4. 乘号字形补全：`[*×xX]` → `[*×xX✕╳⨯]`

### 效果
- `1.8kgX2` / `1.8kg*2` / `2L×6` → name 到规格，qty=2 / 6 ✅
- `MM300毫升×48矿泉水` → 保持整体，qty=1 ✅（整箱语义不变）
- `蒙牛冠益乳发酵乳100g*24*1` → name 含 "100g×24"，qty=1 ✅（不影响）
